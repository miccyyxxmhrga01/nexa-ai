<<<PROMPT>>>
Make an analog clock in VPython that shows the real time.
<<<ANSWER>>>
Three arrows for the hands, turned to match the current time every tenth of a second:

```python
import time
from vpython import *

scene.title = "VPython clock"
scene.range = 1.3
scene.userspin = False  # keep it facing us

ring(pos=vector(0, 0, 0), axis=vector(0, 0, 1), radius=1.05, thickness=0.04, color=color.gray(0.7))
for i in range(60):
    angle = pi / 2 - 2 * pi * i / 60
    size = 0.1 if i % 5 == 0 else 0.04  # longer marks for the hours
    box(pos=vector(0.95 * cos(angle), 0.95 * sin(angle), 0), axis=vector(cos(angle), sin(angle), 0),
        size=vector(size, 0.02, 0.02), color=color.white)

hour = arrow(pos=vector(0, 0, 0.02), shaftwidth=0.06, color=color.white)
minute = arrow(pos=vector(0, 0, 0.04), shaftwidth=0.04, color=color.cyan)
second = arrow(pos=vector(0, 0, 0.06), shaftwidth=0.015, color=color.red)
sphere(pos=vector(0, 0, 0.07), radius=0.04, color=color.gray(0.4))
readout = label(pos=vector(0, -1.25, 0), text="", box=False, height=16)


def hand_direction(fraction):
    """fraction 0 = 12 o'clock, 0.25 = 3 o'clock, going clockwise."""
    a = pi / 2 - 2 * pi * fraction
    return vector(cos(a), sin(a), 0)


while True:
    rate(10)
    now = time.localtime()
    s = now.tm_sec
    m = now.tm_min + s / 60
    h = now.tm_hour % 12 + m / 60
    second.axis = 0.9 * hand_direction(s / 60)
    minute.axis = 0.8 * hand_direction(m / 60)
    hour.axis = 0.5 * hand_direction(h / 12)
    readout.text = time.strftime("%H:%M:%S", now)
```

Angles in math go counterclockwise from 3 o'clock, so `pi / 2 - 2 * pi * fraction` starts at 12 o'clock and goes clockwise like a real clock. The minute and hour values include the smaller units so those hands move smoothly instead of jumping.

<<<PROMPT>>>
Build a 3D model of a water molecule in VPython.
<<<PROMPT>>>
How do I make a ball-and-stick molecule in VPython?
<<<ANSWER>>>
Atoms are spheres and bonds are cylinders. Water's two hydrogens sit 104.5° apart around the oxygen:

```python
from vpython import *

scene.title = "Water (H2O)"
scene.background = color.white

bond_length = 1.0
half_angle = radians(104.5 / 2)

O = sphere(pos=vector(0, 0, 0), radius=0.4, color=color.red)
H1 = sphere(pos=bond_length * vector(sin(half_angle), -cos(half_angle), 0), radius=0.25, color=color.gray(0.9))
H2 = sphere(pos=bond_length * vector(-sin(half_angle), -cos(half_angle), 0), radius=0.25, color=color.gray(0.9))
bond1 = cylinder(pos=O.pos, axis=H1.pos - O.pos, radius=0.08, color=color.gray(0.5))
bond2 = cylinder(pos=O.pos, axis=H2.pos - O.pos, radius=0.08, color=color.gray(0.5))

molecule = compound([O, H1, H2, bond1, bond2])
label(pos=vector(0, 0.9, 0), text="H2O  bond angle 104.5 degrees", box=False, height=14, color=color.black)

while True:
    rate(60)
    molecule.rotate(angle=0.01, axis=vector(0, 1, 0))
```

Each bond is a cylinder from the oxygen with `axis = H.pos - O.pos`, so it always reaches exactly to the hydrogen. The same pattern builds any molecule: place the atoms, then connect them.

<<<PROMPT>>>
Make Saturn with its rings in VPython.
<<<ANSWER>>>
A `ring` is a flat torus; stacking a few with different radii and colors makes the ring system. Everything is tilted with `axis`:

```python
from vpython import *

scene.title = "Saturn"
scene.background = color.black

tilt = vector(sin(radians(27)), cos(radians(27)), 0)  # Saturn's axis is tilted about 27 degrees

planet = sphere(pos=vector(0, 0, 0), radius=1, color=vector(0.93, 0.82, 0.6))
rings = []
for radius, shade in ((1.5, 0.75), (1.75, 0.9), (2.0, 0.65), (2.25, 0.8)):
    rings.append(ring(pos=planet.pos, axis=tilt, radius=radius, thickness=0.11,
                      color=vector(shade, shade * 0.9, shade * 0.7), opacity=0.8))

moon = sphere(pos=vector(4, 0, 0), radius=0.12, color=color.gray(0.8), make_trail=True, retain=200)

t = 0
while True:
    rate(60)
    t += 0.01
    planet.rotate(angle=0.03, axis=tilt)
    moon.pos = vector(4 * cos(t), 0.4 * sin(t), 4 * sin(t))
```

For a `ring`, `axis` points through the hole, `radius` is from the center to the middle of the band, and `thickness` is how fat the band is.

<<<PROMPT>>>
Make a rotating DNA double helix in VPython.
<<<ANSWER>>>
Two strands wind around the same axis half a turn apart, with colored base pairs connecting them:

```python
from vpython import *

scene.title = "DNA double helix"
scene.background = color.black

parts = []
pairs = [(color.red, color.green), (color.blue, color.yellow)]  # A-T and C-G
turns = 3
steps_per_turn = 10
R = 1
rise = 0.35  # height per step

for i in range(turns * steps_per_turn):
    angle = 2 * pi * i / steps_per_turn
    y = i * rise - turns * steps_per_turn * rise / 2
    a = vector(R * cos(angle), y, R * sin(angle))
    b = vector(R * cos(angle + pi), y, R * sin(angle + pi))  # the other strand, opposite side
    parts.append(sphere(pos=a, radius=0.15, color=color.white))
    parts.append(sphere(pos=b, radius=0.15, color=color.white))
    left, right = pairs[i % 2]
    mid = (a + b) / 2
    parts.append(cylinder(pos=a, axis=mid - a, radius=0.06, color=left))
    parts.append(cylinder(pos=mid, axis=b - mid, radius=0.06, color=right))

dna = compound(parts)
while True:
    rate(60)
    dna.rotate(angle=0.01, axis=vector(0, 1, 0))
```

Each step goes up by `rise` and around by `2π / steps_per_turn`. The second strand adds `pi` to the angle, which puts it on the opposite side.

<<<PROMPT>>>
Roll two dice many times in VPython and show a live histogram of the totals.
<<<PROMPT>>>
How do I make a bar chart in VPython?
<<<ANSWER>>>
`gvbars` draws vertical bars. Keep the counts in a list and replace the bars' `data` as the rolls come in:

```python
from vpython import *
from random import randint  # see the note below

g = graph(title="Sum of two dice", xtitle="total", ytitle="count", xmin=1, xmax=13, width=600, height=350)
bars = gvbars(graph=g, delta=0.8, color=color.blue)
expected = gdots(graph=g, color=color.red, label="expected", radius=3)

counts = [0] * 13  # index = total (2 to 12)
rolls = 0
while rolls < 5000:
    rate(200)
    total = randint(1, 6) + randint(1, 6)
    counts[total] += 1
    rolls += 1
    if rolls % 50 == 0:  # redraw every 50 rolls
        bars.data = [[t, counts[t]] for t in range(2, 13)]

# The theory: 6 - |total - 7| ways out of 36
expected.data = [[t, rolls * (6 - abs(t - 7)) / 36] for t in range(2, 13)]
```

How it works:
- `delta` is the width of each bar, and setting `bars.data` replaces all the bars at once.
- The red dots show the expected counts, so you can see the random results match the theory more closely as the number of rolls grows.
- Note the import: `from vpython import *` brings in its own `random()` function, so if you write `import random` *before* it, the name `random` gets replaced and `random.randint` fails. Importing `randint` directly avoids that.

<<<PROMPT>>>
Make a 3D surface plot of z = sin(x) * cos(y) in VPython.
<<<ANSWER>>>
Sample the function on a grid and draw each point, colored by height. `points` handles thousands of dots quickly:

```python
from vpython import *

scene.title = "z = sin(x) cos(y)"
scene.background = color.white
scene.forward = vector(-1, -1, -1)

dots = points(radius=4)
N = 60
span = 2 * pi
for i in range(N):
    for j in range(N):
        x = -span / 2 + span * i / (N - 1)
        y = -span / 2 + span * j / (N - 1)
        z = sin(x) * cos(y)
        hue = 0.7 * (1 - (z + 1) / 2)  # blue for low, red for high
        # VPython's y axis points up, so the function's value goes in y
        dots.append(pos=vector(x, z * 1.5, y), color=color.hsv_to_rgb(vector(hue, 1, 1)))

for direction, c, name in ((vector(1, 0, 0), color.red, "x"), (vector(0, 1, 0), color.green, "z"),
                           (vector(0, 0, 1), color.blue, "y")):
    arrow(pos=vector(0, 0, 0), axis=direction * 4, shaftwidth=0.04, color=c)
    label(pos=direction * 4.3, text=name, box=False, height=14)
```

Drag with the right mouse button to look at it from different sides. The math y axis is drawn along VPython's z axis because VPython's y axis points up.

<<<PROMPT>>>
Add a checkbox to show or hide a trail and a text box to type a speed in VPython.
<<<PROMPT>>>
How do I use checkbox and winput in VPython?
<<<ANSWER>>>
A spinning wheel with a dot on its rim. The checkbox turns the dot's trail on and off, and you type the spin speed into the input box:

```python
from vpython import *

scene.title = "Spinning wheel"
scene.range = 3

wheel = cylinder(pos=vector(0, 0, -0.1), axis=vector(0, 0, 0.2), radius=2, color=color.gray(0.5))
dot = sphere(pos=vector(2, 0, 0.15), radius=0.12, color=color.red, make_trail=False, retain=150)
speed = 1.0  # radians per second


def toggle_trail(box):
    dot.make_trail = box.checked
    if not box.checked:
        dot.clear_trail()


def set_speed(field):
    global speed
    if field.number is not None:  # None if the text isn't a number
        speed = field.number
        status.text = f"  speed = {speed} rad/s"


checkbox(text="Show trail", checked=False, bind=toggle_trail)
scene.append_to_caption("\n\nSpin speed (rad/s): ")
winput(type="numeric", bind=set_speed)
status = wtext(text=f"  speed = {speed} rad/s")

angle = 0
dt = 0.02
while True:
    rate(50)
    angle += speed * dt
    dot.pos = vector(2 * cos(angle), 2 * sin(angle), 0.15)
```

`checkbox` gives your function the checkbox, so read `box.checked`. A `winput` with `type="numeric"` gives you `field.number` after you press Enter (or `field.text` for the raw text).

<<<PROMPT>>>
Make a 3D game in VPython: a ball bounces around a room and I block it with a paddle using the arrow keys.
<<<ANSWER>>>
The ball bounces off the walls of a box-shaped room. The open front is guarded by your paddle, and if the ball gets past it, you lose a life:

```python
from vpython import *

scene.title = "3D paddle - arrow keys move the paddle"
scene.range = 8
scene.forward = vector(0, -0.2, -1)
scene.userspin = False

W, H, D = 6, 4, 10  # half width, half height, depth of the room
for pos, size in ((vector(-W, 0, -D / 2), vector(0.1, 2 * H, D)), (vector(W, 0, -D / 2), vector(0.1, 2 * H, D)),
                  (vector(0, -H, -D / 2), vector(2 * W, 0.1, D)), (vector(0, H, -D / 2), vector(2 * W, 0.1, D)),
                  (vector(0, 0, -D), vector(2 * W, 2 * H, 0.1))):
    box(pos=pos, size=size, color=color.gray(0.4), opacity=0.3)

paddle = box(pos=vector(0, 0, 0), size=vector(2.5, 1.5, 0.2), color=color.cyan, opacity=0.6)
ball = sphere(pos=vector(0, 0, -5), radius=0.4, color=color.orange)
ball.velocity = vector(3, 2, 6)
info = label(pos=vector(0, H + 1.2, 0), text="", box=False, height=16)
score, lives = 0, 3

dt = 0.01
while lives > 0:
    rate(100)
    keys = keysdown()
    paddle.pos.x += (("right" in keys) - ("left" in keys)) * 8 * dt
    paddle.pos.y += (("up" in keys) - ("down" in keys)) * 8 * dt
    paddle.pos.x = max(-W + 1.25, min(W - 1.25, paddle.pos.x))
    paddle.pos.y = max(-H + 0.75, min(H - 0.75, paddle.pos.y))

    ball.pos = ball.pos + ball.velocity * dt
    r = ball.radius
    if ball.pos.x > W - r:
        ball.velocity.x = -abs(ball.velocity.x)
    elif ball.pos.x < -W + r:
        ball.velocity.x = abs(ball.velocity.x)
    if ball.pos.y > H - r:
        ball.velocity.y = -abs(ball.velocity.y)
    elif ball.pos.y < -H + r:
        ball.velocity.y = abs(ball.velocity.y)
    if ball.pos.z < -D + r:
        ball.velocity.z = abs(ball.velocity.z)

    if ball.pos.z > -r and ball.velocity.z > 0:  # reached the front
        if abs(ball.pos.x - paddle.pos.x) < 1.25 + r and abs(ball.pos.y - paddle.pos.y) < 0.75 + r:
            ball.velocity.z = -abs(ball.velocity.z) * 1.05  # blocked: send it back a bit faster
            score += 1
        else:
            lives -= 1
            ball.pos = vector(0, 0, -5)
            ball.velocity = vector(3, 2, 6)
    info.text = f"Score {score}   Lives {lives}"

info.text = f"Game over! Score {score}"
```

Click the scene first so it gets your key presses. The ball's z position tells you how deep in the room it is, and the paddle check compares x and y only when the ball reaches the front.

<<<PROMPT>>>
In VPython, let me click to launch satellites that orbit a planet.
<<<ANSWER>>>
Each click makes a satellite at the mouse position, moving at exactly the speed needed for a circular orbit at that distance:

```python
from vpython import *

scene.title = "Click to launch satellites"
scene.background = color.black
scene.range = 12
scene.autoscale = False

G = 1
planet = sphere(pos=vector(0, 0, 0), radius=1.5, texture=textures.earth)
planet.mass = 500
satellites = []


def launch(evt):
    r = evt.pos - planet.pos
    if mag(r) < planet.radius + 0.3:
        return  # clicked on the planet itself
    speed = sqrt(G * planet.mass / mag(r))          # circular orbit speed
    direction = cross(vector(0, 0, 1), r).hat        # sideways, in the screen plane
    s = sphere(pos=evt.pos, radius=0.2, color=color.hsv_to_rgb(vector(random(), 0.6, 1)),
               make_trail=True, retain=300)
    s.velocity = direction * speed
    satellites.append(s)


scene.bind("click", launch)

dt = 0.002
while True:
    rate(500)
    for s in satellites:
        r = s.pos - planet.pos
        s.velocity = s.velocity - G * planet.mass * r.hat / mag2(r) * dt
        s.pos = s.pos + s.velocity * dt
    planet.rotate(angle=0.002, axis=vector(0, 1, 0))
```

`cross(vector(0, 0, 1), r)` gives a vector perpendicular to `r` in the plane of the screen, which is the right direction for a circular orbit. Try multiplying `speed` by 0.8 or 1.2 to get elliptical orbits.
